================================================================================
 PLASMID DATA — METHODOLOGY
 Dataset construction, metadata acquisition, and analysis, end to end
 Last updated: 2026-07-10
================================================================================

This document records EVERYTHING done to date: where every sequence and every
metadata field came from, exactly how it was downloaded, how the working set was
built, how each metadata layer was joined, and what the investigation notebook
computes. Each output names the exact script that produces it (so any number can
be traced and regenerated).

All paths are relative to the project root:
  /proj/h-mel-phylo/h-mel-phylo/private/amar/plasmid_analyis

Compute environment:
  - Login node has internet; compute nodes do NOT. All downloads/fetches were run
    on the login node. All heavy processing/plotting uses the `genesis` conda env
    (python 3.13/3.14, pandas 3.0.2, matplotlib 3.10.8).
  - Notebook is executed with the `genesis_nb` Jupyter kernel via nbconvert.


================================================================================
 0 · OBJECTIVE
================================================================================

Assemble a single, non-redundant, high-quality reference set of COMPLETE (closed)
plasmids that are NOT laboratory constructs, and attach to every plasmid the
maximum possible metadata — data-source provenance, physical properties, sampling
environment (habitat), replicon/Inc typing, AMR, and geography — with every field
tagged by the source it came from and kept in raw form alongside the harmonised
version.

Final working set:  208,248 plasmids
Clean analysis set: 143,503 plasmids (working set minus two non-habitat buckets,
                    see §5.2)


================================================================================
 1 · PRIMARY DATA SOURCE AND WHY
================================================================================

PlasmidScope (NAR Database issue, 2025) is the PRIMARY database. It is itself a
consolidation of ten plasmid resources, already deduplicated across and within
them. We adopt it as primary because it is the broadest complete-plasmid catalogue
that spans BOTH metagenomic (IMG/PR, mMGE) and isolate (RefSeq, GenBank, PLSDB,
COMPASS, ENA, DDBJ, Kraken2, TPA) origins — the environmental breadth is the point
of the project.

The ten contributing databases (PlasmidScope `Data_Source` tag):
  IMG-PR   metagenome   RefSeq   isolate
  mMGE     metagenome   GenBank  isolate
                        PLSDB    isolate
                        COMPASS  isolate
                        ENA      isolate
                        DDBJ     isolate
                        Kraken2  isolate
                        TPA      isolate

PIPdb (NAR 2025, D169) was assessed and REJECTED as a source (pathogen-only,
predicted contig/segment clusters not closed plasmids, not accession-joinable). It
reintroduces clinical bias and fails the completeness gate. See
METADATA_ENRICHMENT_PLAN.md §4 for the full assessment. It is excluded entirely.


================================================================================
 2 · DATA DOWNLOAD — EXACTLY HOW, AND FROM WHERE
================================================================================

Every network artefact used, with its origin, method, and landing location.

--------------------------------------------------------------------------------
2.1 · IMG/PR complete plasmids (the metagenomic seed)
--------------------------------------------------------------------------------
Source : JGI IMG/PR release IMG_VR_2023-08-08_1.
Files  : data/Cus_PR/IMG_VR_2023-08-08_1/
           IMGPR_plasmid_data.tsv   per-plasmid table (plasmid_id, taxon_oid,
                                    GOLD ecosystem, scaffold, length, topology…)
           complete_plasmids.fna    the IMG/PR complete-plasmid nucleotide FASTA
                                    (header: IMGPR_plasmid_..|taxon_oid|scaffold)
Note   : This IMG/PR complete set was already present at project start; PlasmidScope
         re-exports the identical IMG-PR complete sequences, so the per-source
         PlasmidScope FASTA download (§2.3) deliberately SKIPS IMG-PR to avoid a
         2.8 GB duplicate — IMG/PR sequences come from this local FASTA instead.
         (complete_plasmids.fna was deleted after sequence consolidation, §4.4; the
         table IMGPR_plasmid_data.tsv is kept — it carries the GOLD ecosystem and
         the taxon_oid needed for the geography scrape.)

--------------------------------------------------------------------------------
2.2 · PlasmidScope ALL master + per-source metadata tables
--------------------------------------------------------------------------------
Source : PlasmidScope API,  https://plasmidapi.deepomics.org/api/database/files
Script : scripts/download_plasmidscope_metadata.sh   (curl, per-source)
Fetched:
  - ALL.plasmid_list   -> data/plasmidscope_primary/all_metadata.tsv  (101 MB)
      PlasmidScope's DEDUPLICATED master: one row per non-redundant plasmid, with
      Plasmid_ID (comma-joined set of the original per-source IDs it was collapsed
      from), Data_Source (set of contributing DBs), Completeness, GC content,
      length, topology, host/organism, MOB relaxase family, predicted mobility.
  - <DB>.plasmid_list.download.tsv for each of the 9 non-primary DBs
      -> data/PlasmidScope/metadata/<DB>.plasmid_list.tsv  (per-source detail)

--------------------------------------------------------------------------------
2.3 · PlasmidScope per-source nucleotide FASTA archives
--------------------------------------------------------------------------------
Source : same API base, files <DB>/<DB>.fasta.tar.gz
Script : scripts/download_plasmidscope_fasta.sh   (curl, smallest DB first)
Fetched: RefSeq, GenBank, PLSDB, COMPASS, DDBJ, ENA, Kraken2, mMGE archives
         -> data/PlasmidScope/fasta/<DB>.fasta.tar.gz
Structure quirk : each archive stores ONE .fasta file PER sequence (thousands of
         members); FASTA headers begin with the exact provenance id
         (e.g. >GenBank_CP028544.1). IMG-PR intentionally NOT downloaded (see §2.1).
         (These 6.7 GB of archives were deleted after §4.4 consolidation.)

--------------------------------------------------------------------------------
2.4 · PLSDB 2025 curated META archive (the richest isolate metadata layer)
--------------------------------------------------------------------------------
Source : PLSDB 2025, host www.ccb.uni-saarland.de/plsdb2025/
         bulk file /plsdb2025/download_meta.tar.gz  (~3.65 GB; version 2024_05_31_v2,
         72,556 plasmids). Downloaded manually with curl on the login node (the old
         ccb.uni-saarland.de host DNS-fails on this node; the plsdb2025 host works;
         the server ignores HTTP Range and streams the whole archive).
Extract: the 199 MB of CURATED TABLES were kept, the large sketch/protein/sequence
         members discarded, into data/PLSDB/plsdb2025_meta/ :
           nuccore.csv          accession <-> UID, length, topology, dates
           biosample.csv        BioSample attrs (keyed on LIST-valued NUCCORE_UID)
           biosample_attributes_plsdb.csv
           plasmidfinder.csv    PlasmidFinder replicon / Inc typing
           typing.csv, typing_markers.csv   MOB-suite typing, relaxase, mob cluster
           amr.tsv              AMRFinder/CARD AMR genes + drug classes
           ecopaths.csv         hierarchical ecosystem tags (controlled vocab)
           disease_terms.csv    disease ontology terms
           taxonomy.csv         host taxonomy lineage
           assembly.csv, changes.tsv, nucc_identical.csv, README.md, mash sim
         All keyed by NUCCORE_ACC (NCBI accession).

--------------------------------------------------------------------------------
2.5 · NCBI BioSample / INSDC source metadata (environment + geography for isolates)
--------------------------------------------------------------------------------
For every INSDC-backed plasmid (RefSeq/GenBank/PLSDB/COMPASS/ENA/DDBJ/Kraken2/TPA)
the provenance carries an NCBI nuccore accession, but the environment lives on the
linked BioSample, not in the sequence record.
Script : scripts/fetch_biosample_env.py   (login node, resumable)
Method : batched NCBI efetch  db=nuccore  rettype=gb  seq_start=1 seq_stop=2
         — truncates the sequence to 2 bp but PRESERVES the FEATURES `source`
         qualifiers. ~150 accessions/request, ~840 requests.
Parsed fields -> data/processed/plasmidscope/biosample/env_raw.tsv :
         accession, organism, isolation_source, host, geo_loc_name, lat_lon,
         collection_date.

--------------------------------------------------------------------------------
2.6 · mMGE SRA sample metadata (environment for the human-microbiome metagenomic DB)
--------------------------------------------------------------------------------
mMGE plasmids carry an SRA run accession (SRR/DRR/ERR) rather than a nuccore acc.
Script : scripts/fetch_sra_env.py   (login node, resumable)
Method : NCBI efetch  db=sra  retmode=xml ; parse SAMPLE organism + attributes.
Parsed -> data/plasmidscope_primary/sra_env_raw.tsv :
         run, organism, host, isolation_source, geo_loc_name, body_site,
         raw_attributes.

--------------------------------------------------------------------------------
2.7 · IMG/M sample geography (coordinates for the metagenomic IMG/PR plasmids)
--------------------------------------------------------------------------------
IMG/PR gives only a taxon_oid (the IMG/M dataset a plasmid was found in) — no
coordinates. IMG/M taxon pages DO expose Latitude / Longitude / Geographic Location
/ Country / Collection Date (sourced from GOLD), but GOLD/IMG are login-gated.
Auth   : a JGI session token (provided by the user) sent as the `jgi_session`
         cookie via env var IMG_SESSION. NEVER hard-coded; tokens EXPIRE (re-request
         from the user to re-run).
Script : scripts/scrape_img_geo.py  (12 concurrent workers; endpoint 3300* ->
         IMG/M MetaDetail; resumable; polite; aborts if the session looks expired)
Scope  : the 136,316 IMG/PR working-set plasmids collapse to 26,149 distinct taxa;
         only the 10,582 metagenome (3300*) taxa were scraped (isolate taxa carry no
         IMG coords and are already INSDC-geo'd).
Output : data/GOLD/img_taxon_geo.tsv  (taxon_oid, lat, lng, geo_location, country,
         collection_date, habitat) — 10,466/10,582 (98.9%) got geography.
GOLD bulk export stayed 403 even with the token; the MetaDetail page-scrape is the
workaround.


================================================================================
 3 · DEDUPLICATION (INHERITED FROM PLASMIDSCOPE)
================================================================================

No dedup was performed by us. PlasmidScope's `ALL` table IS the non-redundant set:
duplicates were detected with MMseqs2 v15.6f452 at 100% identity AND 100% coverage
(--cov-mode 0 -c 1.0 --min-seq-id 1.0); surviving plasmids each carry the set of
source DBs they were collapsed from. Consequence: there are NO cross-database or
within-database duplicate plasmids in anything downstream. 348,617 raw source
entries consolidate into the complete set (avg 1.67 sources/plasmid) — dedup
merges provenance, it does not drop biology.
Producer: scripts/characterize_plasmidscope_all.py -> complete_provenance.tsv,
          reports/plasmidscope_primary_characterization.md

    208,360  complete
    −   112  lab-made/synthetic
    =======
    208,248  WORKING SET   (everything else kept, incl. 'unknown' environment)
Producer: scripts/assemble_working_set.py -> working_set.tsv,

4.4 · Sequence consolidation  (scripts/build_working_set_fasta.py)

This is the sequence file the future replicon-typing run needs; producing it let us
delete the 9.5 GB of raw archives + the IMG/PR FASTA (project 30 GB -> 18 GB).


================================================================================
 5 · METADATA LAYERS — HOW EACH FIELD IS DERIVED
================================================================================

Everything is keyed to the representative id (`plasmid_id` = first member of the
comma-joined provenance set). Every layer keeps its source; raw labels are retained
alongside the harmonised value.

--------------------------------------------------------------------------------
5.1 · Physical + core provenance  (scripts/build_analysis_table.py)
--------------------------------------------------------------------------------
Left-joins the two fields that live only in PlasmidScope's master onto the working
set (join verified 208,360/208,360):
    gc_percent      GC content
    mob_families    unique MOB* relaxase families (';'-joined; '' = non-typeable)
    n_source_dbs    provenance multiplicity
plus topology, size_bp, predicted_mobility carried from provenance/master, and the
RAW environment channels (gold_ecosystem, biosample_host, biosample_isolation_source,
sra_sample) needed by the reconciler.
Output: data/plasmidscope_primary/analysis_table.tsv

--------------------------------------------------------------------------------
5.2 · Environment reconciliation — the LOCKED taxonomy
       (scripts/reconcile_environment.py ; doc reports/environment_taxonomy_LOCKED.md)
--------------------------------------------------------------------------------
Raw environment labels come from three CHANNELS, priority GOLD > BioSample > SRA:
    GOLD       IMG/PR `ecosystem` string       (local, recover_env_local.py)
    BioSample  isolation_source + host         (fetched, §2.5)
    SRA        mMGE sample organism/attributes (fetched, §2.6)
recorded per plasmid in `hab_channel` (which channel supplied the final label).

Harmonisation:
  - GOLD paths mapped structurally (classify_gold): e.g.
    Host-associated;Mammals:Human -> Human: unspecified ; Environmental;Aquatic ->
    Aquatic: freshwater/other ; Engineered;Wastewater/WWTP -> Wastewater/sewage.
  - Free-text BioSample/SRA mapped by an ORDERED, first-match-wins keyword ruleset
    (classify_freetext) — e.g. wastewater BEFORE water; feces/stool -> Human:
    gut/faeces; hospital/clinical terms -> clinical sites.

Two output axes, deliberately SEPARATE:
    sources                  = database provenance (NOT an environment)
    hab_top / hab_sub        = the reconciled HABITAT (where it was sampled)
    is_clinical              = additional flag under Host-associated;Human:
                               clinical body site OR a PLSDB disease term OR a
                               hospital/patient/nosocomial context (19,446 = 9.3%)
The metagenomic-vs-isolate "lifestyle" tag was DROPPED (a source-DB tag does not
reflect true sample origin; clinical datasets contain metagenomic samples).

Top-level result (208,248):
    Host-associated     65,108   human(+body site), livestock, poultry, insect, plant
    Simulated-artifact  64,658   GOLD Modeled;Simulated communities — EXCLUDED (§5.3)
    Unknown             39,331   unresolved + unlabelled + geography-only, merged
    Environmental       24,693   aquatic, terrestrial/soil, air, extreme
    Engineered          14,371   REAL sites: wastewater/WWTP, bioreactor, built-env,
                                 food/fermentation, solid-waste, industrial/remediation
    Lab-artifact            87   EXCLUDED (§5.3)
Output: data/plasmidscope_primary/environment_reconciled.tsv
        (plasmid_id, hab_top, hab_sub, hab_channel, is_clinical)

--------------------------------------------------------------------------------
5.3 · The two EXCLUDED non-habitat buckets
--------------------------------------------------------------------------------
Real sequences, kept in provenance/physical/typing, but removed from every
environmental and geographic view because they are not a real field habitat:
  Simulated-artifact  64,658  GOLD "Engineered;Modeled;Simulated communities".
                              In-silico community samples; their coordinates all
                              collapse onto the JGI compute site (Berkeley), so any
                              geography is spurious.
  Lab-artifact            87  GOLD "Lab enrichment" (60, lab enrichment cultures on
                              defined/aerobic/anaerobic media) + content-free bare
                              "Engineered" with no second level (27). Not an
                              environmental-engineering SITE; no field origin.
    Analysis set = 208,248 − 64,658 − 87 = 143,503.

--------------------------------------------------------------------------------
5.4 · PLSDB enrichment  (scripts/enrich_plsdb_metadata.py)
--------------------------------------------------------------------------------
For every PLSDB-sourced plasmid, join the curated PLSDB tables (§2.4) by NCBI
accession pulled from provenance (biosample.csv exploded via its LIST-valued
NUCCORE_UID -> ACC map). Matched 45,743 / 47,215 (96.9%).
Adds (prefix plsdb_): PlasmidFinder Inc/rep types + count, MOB-suite relaxase /
mobility / mob cluster, AMR genes + count + drug classes, ecosystem tags (controlled
vocab), disease tags, species.
Coverage on the whole working set: Inc typing 24,872 (12%); any AMR gene 17,271;
ecosystem 39,455; disease 10,192.
Output: data/plasmidscope_primary/plsdb_enrichment.tsv

--------------------------------------------------------------------------------
5.5 · Geography — maximised and coalesced  (scripts/build_metadata_master.py + geo_utils.py)
--------------------------------------------------------------------------------
Per plasmid, the single best location is chosen by a PRIORITY chain:
  1. explicit point coordinate — BioSample lat_lon, else PLSDB lat/lng   (precision=point)
  1b IMG/M scraped coordinate (metagenomic IMG/PR, §2.7)                 (precision=point)
  2. country centroid from a place name (BioSample geo_loc_name, else PLSDB
     location, else SRA geo_loc_name)                                    (precision=country_centroid)
  3. place name but no centroid                                          (precision=country_only)
Centroids are EMPIRICAL: the median of the real coordinate points we already hold
per country (129 countries), plus a 44-country hand fallback for the tail
(geo_utils.py). Each plasmid records geo_source (which layer won), geo_precision,
geo_country, geo_admin1, geo_lat, geo_lng, collection_date.
Simulated-artifact coordinates are flagged/excluded (§5.3).
Real coverage on the analysis set (143,503): country 109,712 (76.5%); coordinates
109,355 (76.2%); collection_date 90,229 (62.9%). geo_source split: img_gold ~46k,
plsdb ~27k, biosample_latlon ~19k, geoname_centroid ~17k.

================================================================================
 7 · ANALYSIS — THE INVESTIGATION NOTEBOOK
================================================================================

Built by  scripts/build_investigation_notebook.py  (emits the .ipynb),
executed with the genesis_nb kernel via nbconvert.
Notebook   notebooks/plasmid_data_investigation.ipynb   (29 cells, 17 figures)
Figures    reports/figures/investigation/*.png

Figure design follows the dataviz method: a validated colorblind-safe categorical
palette; the chart form chosen by the data's job (magnitude->bar, distribution->
histogram, density->hexbin, ordered scale->sequential ramp); fixed categorical
order; single hue for single-series magnitude; and an explicit coverage caveat on
every panel drawn from a subset. Physical/provenance panels use all 208,248
plasmids; every environmental/geographic panel uses the 143,503 analysis set.

Sections:
  0  setup + dataset-at-a-glance stat tiles
  1  provenance: per-DB membership, provenance multiplicity
  2  physical: size (log), GC, size-vs-GC hexbin, topology, predicted mobility
  3  environment (locked): top-level habitat, sub-habitat top-22 (colored by
     domain), clinical body sites, label channel
  4  typing & AMR (PLSDB subset, labelled as such): top Inc families,
     multireplicon, AMR gene burden, resistance classes
  5  geography: equirectangular world map, top countries, resolution mix,
     collection-year timeline
  6  cross-cutting: mobility x habitat (stacked), size x habitat (box),
     AMR prevalence x habitat
  7  summary + data dictionary

One finding surfaced by §6: host-associated plasmids are ~23% conjugative vs ~5%
for environmental — a real mobility signal across habitats.

================================================================================
 9 · KNOWN LIMITATIONS / CAVEATS
================================================================================

- Replicon (Inc/rep) typing currently covers only the 45,743 PLSDB plasmids (~22%);
  the other ~162k are NOT yet replicon-typed. A genome-wide MOB-suite + PlasmidFinder
  run on working_set.fna.gz is the next pipeline gate. All §4-notebook typing panels
  are conditioned on the PLSDB subset and labelled as such — do not read them as
  whole-set rates.
- Geography is near its ceiling for isolate-backed plasmids (~88%) but limited for
  metagenomic ones; place-name-only records are placed at country centroids
  (geo_precision distinguishes point vs centroid vs country-only).
- Environment coverage: 85.9% of the working set carries some raw label; after
  reconciliation ~73% of the analysis set has a real habitat, ~27% Unknown.
- 3 sequences are missing from working_set.fna.gz (re-fetchable from NCBI).
- The JGI session token used for the IMG geography scrape expires; re-running §2.7
  requires a fresh token from the user.
- PIPdb is excluded by decision (§1).
